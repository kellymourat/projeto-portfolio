# Portfólio Pessoal - Kelly Teixeira

Portfólio desenvolvido para demonstrar minhas **competências em Front-End**, incluindo HTML, CSS e JavaScript, com foco em **design responsivo, interatividade, acessibilidade e boas práticas de desenvolvimento web.**

![Pré-visualização do Projeto](assets/media/projeto-demo.gif)

---

## 🔹 Sobre o Projeto

Este portfólio é uma **Single Page Application (SPA) estática**, ou seja, todas as secções estão numa única página sem recarregamento, com:

- Perfil profissional com foto e links de contacto.  
- Secção de **competências** (habilidades técnicas e interpessoais) com barras de progresso.  
- Secção de **formação**, apresentando cursos e instituições.  
- Secção de **projetos**, cada um com imagem, período, título e descrição detalhada em `<details>`.  
- Tema claro e escuro implementado com **variáveis CSS** e persistência via `localStorage`.  
- Navegação suave entre secções com offset calculado para o cabeçalho.  
- Design responsivo usando **CSS Grid** e **Flexbox**, compatível com dispositivos móveis, tablets e desktops.  
- Ícones vetoriais escaláveis usando **FontAwesome**.
