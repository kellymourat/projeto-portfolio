# projeto portfolio
Projeto de portfólio pessoal desenvolvido com HTML5, CSS3 (Flexbox e Grid Layout) e JavaScript para tornar a navegação interativa e responsiva. A aplicação foi planejada para destacar minhas competências como desenvolvedora Front-End, reunindo informações sobre minha trajetória, projetos práticos e formas de contato em uma interface limpa e de fácil usabilidade.
